# Fin-assist - MVP ideas

### Main issue

Categorization of expenses requires a lot of time to process each expense and label it. It is essential to be aware how much we spend money on each category when it comes to managing home budget.

###  Features included in MVP
- Web application with user management based on simple login + password authentication.
- User can import csv file of some period of time and one known format.
- User can see propositions of labels generated by AI API call and can adjust them.
- User can name this set of records as for example 'May 2026', save it and see the list of saved sets of data.
- User can predefine set of available categories to use.
- User can predefine categories of some records. For example: When record contains "LIDL" this means "Shopping" category.
- There will be "Stats" with graphs of spendings of each category in given period of time.


### What is not included in MVP
- Advanced authentication
- Multiple different formats of data from several banks.
- Own label prediction model
- Mobile application.



### Success criteria
- Successful import of csv file
- 75% correct prediction of labels
